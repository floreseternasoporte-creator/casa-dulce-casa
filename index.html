Cómo se juega

  • Vivir: toca un mueble para ver sus acciones. Toca el suelo para caminar.
  • Construir: elige un mueble, muévelo sobre la parcela y toca para colocarlo. R gira.
  • Táctil: un dedo mueve la cámara, pellizca para acercar, gira dos dedos para rotar y sube o baja dos dedos para inclinar. Ratón: arrastra para rotar, rueda para acercar, clic derecho o Shift para mover.
  • W A S D mueve la cámara, Q E rotan, Espacio pausa, 1 2 3 velocidad.
  • Trabaja en el ordenador para ganar $, y compra muebles nuevos.
  • Teléfono: invita al vecino, pide comida a domicilio o pide el día libre.
  • Trabajo: lun–vie de 9:00 a 17:00, tu Sim sale de casa y vuelve con el sueldo.
  • Facturas: llegan al buzón cada 3 días. Toca el buzón para pagarlas; si se vencen, llevan recargo.
